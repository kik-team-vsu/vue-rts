# Лабораторная 2

## Первые 60%

### Дегтярев

- [ ] **Ромбовидное поле и объекты (подготовка).** В `task2` поле пока прямоугольное. Перевести сетку и основания объектов на ромбовидную проекцию через DOM и CSS, без Canvas и новых библиотек. Прямое и обратное преобразования координат собрать в `vue/src/game/coords.ts`, чтобы `GameField.vue` и `GameObject.vue` пользовались одной системой. Проверить, что после сдвига камеры по-прежнему можно выбрать юнита и отправить его точно в место клика.
- [ ] **Игровой кадр и состояние во Vuex.** Перенести данные карты и объектов из `GameField.vue` в игровой модуль существующего стора. Хранить объекты и текущие события отдельно. ПКМ создаёт команду движения для выбранного юнита, следующий кадр применяет активные команды с учётом прошедшего времени, завершённые команды удаляются. `GameField.vue` и `InfoPanel.vue` читают результат из стора. Готово, когда прежний сценарий «выбрать юнита → отправить в точку → дождаться остановки» работает через стор.

### Шебекина

- [ ] **Суша и вода.** Добавить в данные карты тип местности для каждой клетки и показать оба типа на поле. Завести хотя бы по одному типу юнита для суши и воды. Проверять проходимость на всём отрезке движения, чтобы юнит не пересекал неподходящие клетки даже по пути к разрешённой точке.
- [ ] **Занятые места.** Проверять пересечения по размерам объектов на карте при движении, стройке и спавне. Перед препятствием юнит останавливается. Если два юнита идут в одну точку, они не оказываются друг на друге. Передать Кравченко общую проверку свободного места для зданий и спавна.

### Кравченко

- [ ] **Стройка из панели.** Добавить выбор здания в панели и размещение кликом по карте. Сделать хотя бы два размера основания, например 2×2 и 3×3 клетки. Постройка целиком помещается на карте и занимает свободные клетки. В панели выбирается группа, которой будет принадлежать здание.
- [ ] **Спавн из здания.** При выборе здания в панели доступны разрешённые для него типы юнитов. По кнопке юнит сразу появляется на свободном месте рядом, на подходящей местности, и получает группу здания. Если места нет, показать это в панели.
- [ ] **Панель юнита.** Для выбранного юнита показать характеристики и кнопку «Самоуничтожение». По нажатию убрать юнита с карты, снять выделение и удалить его активную команду.

### Тепляков

- [ ] **Характеристики.** Добавить в описания типов юнитов здоровье, урон за удар, скорость движения и интервал между атаками. Для зданий задать здоровье. Текущее здоровье хранить у конкретного объекта, при создании брать начальное значение из типа. Сохранить разницу в скорости рабочего и воина.
- [ ] **Группы.** Добавить идентификатор группы юнитам и зданиям. На стартовой карте показать хотя бы три группы, различимые на поле и в панели. Юниты всех групп доступны для управления. Декорации вроде деревьев остаются без группы.


## Остальное

- [ ] **Шебекина - очередь команд.** Shift + ПКМ по карте добавляет цель в очередь юнита. Следующая команда начинается после завершения текущей. Обычная команда движения заменяет прежний маршрут.
- [ ] **Шебекина - обход препятствий.** Если прямой путь перекрыт, команда движения строит ближайший доступный обход с учётом местности и занятых мест. Если прохода нет, юнит останавливается. Проверить на здании, которое можно обойти, и на полностью перекрытом проходе.
- [ ] **Тепляков - множественное выделение и движение.** Shift + ЛКМ добавляет юнитов к выделению. Один ПКМ по карте отправляет выбранных юнитов к разным свободным точкам рядом с кликом с учётом их типа местности.
- [ ] **Тепляков - атака.** ПКМ по персонажу или зданию другой группы задаёт атаку. Применять урон с интервалом атакующего юнита, убирать цель при нулевом здоровье и завершать команды, у которых больше нет цели.
- [ ] **Кравченко - пауза, сценарии и конец игры.** Добавить запуск подготовленных расстановок из панели со сбросом предыдущего матча. Пауза останавливает движение и бой, продолжение возобновляет их. Когда юниты или здания остаются только у одной группы, показать победителя и завершить матч. Проверить на сценарии с тремя группами.
